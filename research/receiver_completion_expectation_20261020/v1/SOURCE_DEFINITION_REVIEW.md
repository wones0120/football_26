# Primary source definition

[Official nflfastR fast_scraper dictionary](https://nflfastr.com/reference/fast_scraper.html), checked 2026-10-20, defines cp as probability of completion based on comparable game situations and cpoe as completion minus cp for a pass. The new feature directly consumes cp and complete_pass on matched receiver targets; it does not infer scale from a provider CPOE aggregate.

[Official package overview](https://nflfastr.com/) identifies completion probability as an nflfastR model output. Vendor fitted model/training-version chronology is not supplied by the retained play-by-play source, so no original pregame calibration or current independent prediction claim is made.

High admitted this explicit provider completion-expectation estimand for G09-M02; independent charted catchability is a separate source requirement. That adjudication does not promote the old variant by relabeling: the new output exposes matched observed and expected counts, matched sample and full-rate masks, independently bound same-source native target membership, and separate units.
