# Canonical pregame market feature definitions

`canonical_market_environment_features_v1` implements G19-M01 through M09 from canonical game-scoped market observations and authenticated retained ESPN/DraftKings scoreboard bytes. G19-M10 remains an explicit source/estimand gap: an internal team scoreboard forecast is not available from player fantasy points, and no model is run for this feature package.

Current total/spread (M01/M04) select the latest valid pregame observation with original receipt/observation before the decision and kickoff. Invalid, stale (>24h by default), future, wrong-game/team/week, malformed/naive provider clocks and inconsistent numeric quotes abstain. Equally latest conflicting values abstain rather than choosing a snapshot UUID. Home favored is a negative conventional betting spread; away spread has the opposite sign. Team implied points (M07) are (total − team spread)/2 and opponent points (M08) are (total + team spread)/2, so the pair sums exactly to the total.

The new source extractor uses the existing strict native `parse_scoreboard` current-line parser after actual SourceSnapshot artifact+manifest verification. Exact season/week scoreboard URI, pregame status, canonical home/away/kickoff and unique provider/event checks are retained. The native payload's same DraftKings `open` fields supply opening total/spread (M02/M05); opening and latest displayed `close` sides must agree internally. Movement (M03/M06) is current minus native reported open for that same book. ESPN's `close` while game status is pregame means the latest displayed quote, not a later final closing line. The earliest retained observation is never relabeled an opening quote. Opening publication time is unknown; the opening value becomes known no earlier than the actual retained source observation.

M09 is the raw American-moneyline implied break-even probability: −a/(−a+100) for negative odds, 100/(a+100) for positive odds. Both sides must be supplied, finite and valid. Raw probabilities retain bookmaker margin; overround and separately named proportional two-sided no-vig probabilities are retained for inspection. Neither is claimed to be a calibrated game-win likelihood. Missing one side preserves unknown rather than guessing from spread or favorite labels.

Same-snapshot source IDs bind optional opening/moneyline extraction; the derivation script independently replays the verified native payload and checks current line, spread and native event ID against every completed canonical market observation. Indexed ORM timestamps are UTC (SQLite fixtures may omit the tz marker); untrusted native/provider timestamps remain strictly timezone-aware. Snapshot IDs/capture times remain provenance, separate from measured semantics.

Actual derivation uses retained pre-lock source only, performs no fetch/ingest and writes a new content-addressed descriptive artifact after lock with honest current derivation time. It does not update models, scenarios, saved lineups or user settings. No model/optimizer consumption is claimed under the feature-only priority.
