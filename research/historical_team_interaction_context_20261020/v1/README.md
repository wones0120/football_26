# Retained historical team-market observed responses

Feature-only follow-up for X01-M01–M08. Prior current-season input products and sparse response artifacts remain immutable. This package expands actual same-team/season response coverage using the already retained 2023–25 PBP Parquets and verified native schedule/archived intended line fields. No source is downloaded and no predictive model is fit.

The source reader independently checks original manifest bytes, SHA/size/URI, actual receipt clocks, required schema, native REG game/play/team/GSIS keys and duplicate cardinality. It retains explicit administration/control evidence and excludes only declared non-REG and target-boundary rows. Each season derives the environment and official full-team carry budgets from the **same** event receipt. Team counts include native unmapped actors; the package makes no individual canonical-player attachment or position claim. No raw display name is joined. Source native team aliases are normalized while raw immutable bytes and original native team values remain available.

The bounded measurement scope is REG weeks1–17 (`before_period=season*100+18`); week18 and postseason are explicitly excluded, not presented as missing zeros or an entire-season extract. Reference targets are weeks1–3, strictly before week4. Evaluated response targets are weeks4–17, with all native target slots preserved and missing response/condition values masked. Total q25/q75 and absolute spread q50 are fixed from reference-only market observations, never the evaluated outcomes. Lagged reference parents also use only earlier game periods. Sources were acquired in2026: original contemporaneous historical pregame availability is unknown; no target-period cutoff restores that proof.

- X01-M01: observed physical offensive snaps versus intended pregame total, within each team/season.
- X01-M02: observed matched game-level called-pass fraction versus signed team spread. The official decision denominator is nonspike dropbacks plus designed nonkneel rushes; spikes and kneels are excluded only in this named called-decision rate.
- X01-M03: observed official full-team carries (all rushers, kneels included) versus intended team implied points `(total − signed spread)/2`.

These continuous measurements retain paired exposures, known-sample means, centered cross sums, condition squares and population covariance; they are **not** slopes, regression fits, causal effects or forecasts. M04–M08 reuse the reviewed native home/away × continuous market and fixed-total/spread-bin conditional response definitions. M04/M05 contrast home-versus-away covariances, M06/M07 compare favorite-versus-underdog mean response in high/low totals, and M08 compares close-versus-large signed-spread groups. Every mean/covariance/contrast has explicit same-team/season counts and unknown masks. Unknown bin membership masks every exact cell it could enter while preserving known-member sample measurements. Empty/small cells stay undefined; no shrinkage or probability is invented.

Actual three-season coverage is in `actual_receipt.json`. Each season has32team profiles and416 evaluated native team-game slots. Defined continuous/home-away covariance profiles:21/30/32 for2023/24/25; high-total contrasts11/14/20, low-total12/10/21, close-large20/30/32 per channel. Original source/revision/date metadata, real postlock batch read/derive/publication clocks, source producer lineage and separate full/SF-WAS immutable hashes are retained. These are revised retrospective observations, not complete-game certification or current/pregame serving evidence. Existing component serving guards reject them. Model/optimizer/scenario integration, shrinkage, within-time predictive validation and calibration remain separately pending.

Targeted tests cover same-event source ancestry, official kneel-inclusive budgets, native controls/phase/period selection, byte/clock/schema/identity/duplicate guardrails, observed versus lagged response semantics, unknown carry eligibility and serving prohibition. The serial actual job reads one retained season at a time and releases memory; it does not mutate the DB, source files, aliases or earlier artifacts.
