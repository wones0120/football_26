# G20-M05 exact source-product definition review

This is a documentation investigation, not a new historical forecast observation or feature approval. No weather value, height or averaging interval has been inferred from a numeric magnitude.

- [Official NWS API grid FAQ](https://weather-gov.github.io/api/gridpoints) identifies the `windSpeed` grid as maximum prevailing wind speed and distinguishes `windGust`. It concerns the numerical grid endpoint, so this alone is insufficient to establish every detail of the formatted hourly JSON product.
- [Official NWS SCN24-50](https://www.weather.gov/media/notification/pdf_2023_24/scn24-50_removal_of_digital_projects_from_forecast.pdf), pages1–2, explicitly identifies the digitalDWML/digitalJSON migration to `/gridpoints/{WFO}/{X},{Y}/forecast/hourly` as the same underlying data with format differences, and explains DWML content negotiation on that endpoint.
- [Official NWS DWML design](https://graphical.weather.gov/xml/mdl/XML/Design/MDL_XML_Design.htm) describes the digital tabular product's hourly wind speed and encodes wind-speed with `type="sustained"`. This is older product documentation; the 2024 migration notice supplies the explicit endpoint chain. This chain supports a source-native prevailing/sustained-hourly product interpretation, pending independent adjudication.
- [NWSI10-201 linked NDFD specification](https://www.weather.gov/media/mdl/ndfd/pd01002001curr.pdf), section3.11, describes NDFD sustained wind at10m valid at the indicated hour; [archived2020 revision](https://www.weather.gov/media/directives/010_pdfs_archived/pd01002001f.pdf) has the same definition. These documents do not by themselves prove the height or averaging duration of a particular retained hourly JSON value. Leave those artifact attributes unknown unless exact source evidence establishes them.
- [Official API service documentation](https://www.weather.gov/documentation/services-web-api) documents the hourly endpoint and content negotiation. The OpenAPI document fetch was unsupported by the browser's content-type reader; no schema contents are asserted from that failed fetch.
