# Recent observed workload features

Feature-only `recent_observed_workload_v1` covers G22-M01 and G22-M02 as declared channel-wise measured variants. It does not forecast a role, establish participation, allocate replacements or enter either model family.

G22-M01 compares one observed team game with eight observed team games; G22-M02 compares three observed team games with all observed team games in the same season before the target period. Pass attempts, rush attempts and targets remain separate units. Each emits the exact periods, arithmetic mean, signed difference and ratio when the reference is positive. Windows overlap; this is an observed descriptive contrast, not independent evidence. A zero reference has an undefined ratio, while the difference remains valid.

Only source team-game periods define windows. A missing player row is unknown even when it may represent inactivity. All required channel observations must be known; no last-positive-game substitution, DNP zero, cross-season or cross-team fill occurs. A stat row does not independently certify snaps. The source universe supplies team periods before requested actor selection and user preferences are never inputs. Canonical UUIDs normalize before duplicate checks. Source row import clocks must exist and be valid at the cutoff; revised imports do not establish original historical pregame availability. Semantic hashes contain measured values, period windows and definitions, with retrieval IDs/clocks separately retained as provenance.

Actual derivation reads 19,714 retained original weekly records using the existing canonical native-alias history query and the already verified 168-actor SF/WAS roster. At Week6 only five same-season team games exist, so G22-M01's eight-game contrast correctly has zero complete actors; G22-M02 has 12 complete actors per channel. All other contrasts remain unknown. The original source cutoff is October19 23:00:39Z, but derivation is after lock and explicitly descriptive/non-serving. No new ingestion, alias writes, models, scenarios, optimizer run or settings change occurs.

This package requests partial-variant classification, not two universally complete catalog features. Broader workload channels such as routes and snaps are not available in this weekly count contract. The actual artifact and source-query code remain separately identified; earlier artifacts are preserved.
