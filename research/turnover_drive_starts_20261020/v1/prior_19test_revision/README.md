## Implemented definition and actual coverage

`turnover_drive_start_context.py` now implements candidate **X06-M05**. Independent review remains pending. Each incoming physical ORIGINAL drive is indexed to its native opponent defense. Its source-reported start yardline100 (distance to incoming offense's opposing goal) is compared after a typed opponent giveaway against an explicit non-giveaway mixture; smaller values mean better incoming field position. The latter includes separate kickoff, ordinary punt, missed field goal and turnover-on-downs subclasses. Downs are never INT/fumble giveaways. Blocked-kick-downs are supported only with explicit compatible native evidence, with zero certified instances in this extract.

The acquisition is the nearest relevant native event strictly before the first known physical offensive snap. An intervening ordinary physical snap, unknown live action, unknown turnover/recovery, unknown reset, same-event interception/fumble chain or conflicting incoming team/source transition blocks an older origin. Quiet explicit native timeouts/quarter-end/no-play rows can be skipped; a quarter boundary alone never proves a possession reset. Acquisition and incoming snap must report the same known native game-half. A first-snap interception cannot become its own origin. Source-first-play linkage and full native game/play/order-key equality with the reviewed order map are required; numeric play-ID order is never chronology.

INT origin requires a live official nonspike pass, two native sides, explicit interception and no fumble evidence. Lost fumble origin requires the reviewed sole native fumbler/sole native recoverer proof; the loser may be the return team rather than initial offense. Multiple/missing slots and same-play INT+fumble remain unknown, without ordinal pairing. Kickoffs use explicit return-team/own-recovery evidence; kickoff possession team is not automatically the kicking team. Touchdown/unknown touchdown origins require a new reset proof. Proven giveaway anchors without a certified incoming physical drive stay censored.
