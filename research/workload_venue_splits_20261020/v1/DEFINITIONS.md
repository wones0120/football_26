# Observed home/away workload v1 — G21-M01

For each native actor, canonical attachment, season and team, this feature compares average official workload per observed weekly source log at home against away. Pass attempts, official carries (including kneels/scrambles), and official targets remain separate channels. Passing exposure is available only where the upstream source-proven QB metric exists. This is a descriptive association, not a causal venue adjustment or prediction.

Source logs bind to one unique native schedule game by season/week/canonical team. Home and away are source schedule labels; no stadium geography or neutral-site inference overrides them. A conflicting supplied native game rejects the batch. Missing schedule/team retains unknown venue and masks comparisons. Unbound-team actor evidence masks all the actor's same-season comparisons. No raw player-name join occurs. Native/canonical contradictions reject rather than choosing an identity.

Each side needs at least one observed source row. Any unknown official exposure masks that side's exact mean. Missing scheduled player rows never become zero/DNP and are never inserted; therefore this definition is explicitly per observed source log, not per scheduled game or per active game. Source zeros remain zeros. Histories never cross season/team. No role filtering changes the underlying teammate universe or count budgets.

The derivation verifies the High-reviewed immutable weekly component and projected-source byte hashes, current producer binding, plus the indexed immutable schedule through its reviewed loader. Original source/import/capture chronology remains separate from actual read/derivation/publication. Existing native identity queue evidence is inherited, not resolved by this package. All derived outputs are postlock descriptive and ineligible for pregame serving. No model, scenario or optimizer integration is claimed. This is one proposed catalog ID, not three extra IDs.

There is no UI/configuration change; global README/release behavior stays unchanged for this internal-only feature artifact.

## Actual coverage

Authenticated composition produced 7,828 native actor/team/season profiles and 104 selected SF/WAS 2026 profiles. Exact observed-log home-minus-away differences: 249 QB pass-attempt comparisons, 6,503 official-carry comparisons and 6,503 target comparisons. No source rows were unbound from the native schedule. Cohorts without both venues or supported exposure remain undefined. The source is not a complete participation/DNP registry. Actual derivation took 2.24 seconds, with no DB mutations, new source fetches or models.
