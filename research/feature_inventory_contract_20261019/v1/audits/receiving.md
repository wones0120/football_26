## Mechanism, provenance and next decisions

Verified reusable paths are the typed native/canonical storage contracts, explicit canonical FP feature allowlist, workload evidence separation, opt-in frozen count producer, and market/weather context transforms described above. Only E1 has nonempty-value coverage evidence in this audit. Generic JSON/optional feature names do not establish advanced tracking, routes, first-read, pressure, alignment or situational-play coverage. No external provider was contacted; license/product availability is unknown.

Facts present but not shown consumed include most aggregate efficiency components in E1. The canonical FP model does not automatically consume the legacy optional feature grid. Weather has a deliberate display-only boundary. Supplied pregame expected routes are not observed routes and are not evidence of a fitted route forecast. All Analyst assessments remain not_checked: a general packet interface is not per-metric populated or material consumption evidence.

Semantic/provenance risks: attempts are not dropbacks; team/player-row pace proxies are not measured plays/clock; optional route participation can use incompatible denominators; RB-only carry shares differ from complete-team rush shares; legacy grouped-shift/rolling expressions need boundary tests before reuse. Existing common-window zero insertion is an observed implementation behavior, not proof of inactive/DNP. Count-path explicit inactive gap checks and abstention should not be conflated with legacy rolling history. E1 source receipt proves later capture, not original historical predecision publication. No actor canonical join success rate or source denominator completeness was measured.

Cross-group dependencies: G03 pass attempts, G06 carries and G08 targets share physical team budgets; G11 zones partition those same events, G12 touchdowns are outcomes, and G24 combines correlated FP/count/Analyst ancestry. Do not add them as independent votes. Offensive-line G13 and availability G18 need the same verified starting-role roster. G19/G20 context can define historical G21 splits only with available-before-decision clocks; realized score/pace/weather/current-game starting-QB outcomes cannot enter same-game predictors. Preserve unknown actors/residuals before salary/user exclusions.

Smallest later decisions: choose exact denominator and source definitions for candidates with alternatives; choose active-conditional versus scheduled-game workload estimands and gap policy; decide whether advanced charting/tracking sourcing warrants a separate evidence investigation. Verify existing saved inputs and actual consumer lineage before any model feature decision. This audit authorizes no implementation or model promotion and makes no predictive quality recommendation.
