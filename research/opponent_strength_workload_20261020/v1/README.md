# Workload against strictly prior observed EPA-defined defenses

Candidate G21-M09. Feature-only package; no model fit, causal effect, calibrated rating, forecast or activation. “Strong” and “weak” have one explicit source definition: lower versus upper fixed reference tercile of opponent EPA allowed per observed official physical offensive play. EPA is provider-derived measurement, not a raw physical fact or reputation label.

The denominator is the official pass/rush/sack physical union, each native game/play once, including spikes and kneels, excluding explicit nullified/two-point events and known nonoffensive source classes. It retains all actors without name or canonical filters. Native source live-class and missing/no_play semantics follow the reviewed source contract. Missing EPA, unknown eligibility or native sides mask exact game strength; source-sample counts/sums remain separate. A scheduled game absent from the source is unknown, never zero. Complete observed-log exactness does not prove full-game completeness.

Each target defense context pools its strictly prior, same-season last<=8 SCHEDULED games; missing/unknown games remain in the window, never skipped to the latest known game. Every contributing native game, actual maximum period and native side is retained and checked. Target or future contributions reject even when an authored max-clock claims otherwise. First-three-week per-defense pooled summaries define fixed lower/upper reference terciles. Only known reference summaries choose those fixed constants; unknown reference defenses and source exposures remain visible. Evaluation begins week4, after all reference contributions. Degenerate or insufficient reference samples do not force a group. Middle and unknown opponent groups remain separate.

Reviewed weekly official QB pass/rush/target counts join the native schedule and lagged opponent context by game, team, season and player identity. Within each actor/team/season, report observed source-log mean against strong defenses minus mean against weak defenses, with independent channel units/exposures. The first3weeks remain retained reference-period logs rather than evaluation outcomes. Missing count masks its channel; unknown group membership masks all relevant exact cells and contrasts, retaining explicit known-sample summaries. Absent player rows are not DNP/zero. Upstream canonical collisions/unresolved identities and durable review requests remain intact.

Original2023–25 retained Parquet manifests/hashes/received clocks, indexed schedule and reviewed immutable weekly/extract/producer lineage are verified. Actual read/derive/publication clocks remain2026 retrospective clocks; no original pregame availability is invented. The full output retains2026 weekly actor rows with unknown strength because this package loads only2023–25 EPA source contexts. The selected slice explicitly covers historical SF/WAS2023–25, not current2026 serving.
