# X02-M01–M05 — descriptive workload distributions with observed participation

Proposed feature-only definitions; final exact/partial classification requires High review. These measurements never train or serve forecasts or lineups.

For each current-season, same-team, native actor and explicit weekly source role QB/RB/FB/WR/TE, summarize strictly prior observed weekly official opportunity counts only when a separately sourced, canonical UUID + native game + team + period snap record proves positive offensive snaps. Positive snaps certify physical participation, not health, stable/full role or future active probability. Zero/missing snap rows remain unresolved participation, not certified inactive or DNP. Canonical crosswalks and source collision quarantine are inherited from the independently reviewed immutable snap/weekly loaders; never raw name joins.

- X02-M01: sample target-count variance (squared opportunities), denominator n−1, undefined for n<2.
- X02-M02: sample official rush-count variance by the same explicit source roles, including official kneels/scrambles, undefined for n<2.
- X02-M03: sample official pass-attempt variance only for explicit source-proven QB rows, undefined for n<2.
- X02-M04: observed zero-target count / positive-offensive-snap source logs, by explicit role.
- X02-M05: observed zero-carry count / positive-offensive-snap source logs only for source QB/RB/FB applicability. WR/TE rusher applicability is not inferred from an outcome.

An unknown participation log can belong to the active cohort, so it masks the exact cohort descriptor. A missing official count within a proven-positive-snap log masks exact variance/rate. Known-sample descriptors remain separately named. Missing snap identity is unknown, not an alias guess; a verified positive participant lacking a weekly row stays in a separate missing-official-exposure collection, and masks any same canonical actor/team/season profile. Known zero workload remains zero. Absent player rows never generate zero workload. No cross-team/season pooling or stable-role inference; changed source roles split cohorts explicitly.

The descriptive population is retained observed official weekly source records, with positive-snap participants outside that population retained as unknown exposure. It is not independently certified complete active rosters. Unknown positions and canonical identities remain visible. Source revision clocks are actual later receipts, not historical pregame availability. Positive snaps overlap across teammates and are never summed as physical team plays. Source counts are never converted to fantasy points.

The frozen snap revision currently covers only prior 2026 Week1–5; later weekly logs without snap proof remain unknown. Normalized numerical semantics exclude row/ingest/recapture refs; full original receipts, snapshot IDs, source hashes and alias/quarantine evidence remain in immutable provenance. All artifacts are revised/postlock descriptive/nonserving. Historical variance/zero frequency is not a next-game predictive distribution, calibrated probability or causal role effect.
