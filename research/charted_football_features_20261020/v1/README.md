# FTN native charting measurements

Declared catalog definitions: G03-M05 throwaway count and G03-M09 play-action rate on official-inclusive physical QB dropbacks; G08-M06 first-read targets divided by full-team first-read targets; G08-M10 catchable/player-target rate; G09-M09 drops/catchable-player-target rate; G10-M06 screen/player-target share; G10-M10 contested/player-target share; G14-M02 explicit `n_blitzers>0` per opponent physical dropback. The blitz measure is not pressure, five-rusher inference or sack rate.

The physical dropback union counts official pass attempts (including spikes), sacks and official scrambles once. Contradictory known native passer/rusher on a scramble rejects. QB metrics require source-scoped native game/team/position proof; canonical UUID remains the authenticated PBP parent's authority. Receiving metrics do not require a reputation/position guess. Full-team denominators include all native actors, including unresolved canonical identities. First-read share uses all team primary-read targets, not a player's own target count.

Immutable FTN source is joined only on exact normalized native game/play. PBP eligibility and phase are authoritative; no inferred regular-season phase from week number. Missing charting rows/flags are unknown, not false. Drop=true/catchable=false is an inconsistent source pair and masks catchability and drop outcomes. FTN primary code0 is defined only from2023; absent2022 primary evidence remains unknown. Source `date_pulled` is provider API retrieval, not original publication. Passing spike exposure remains in the denominator even if charting is absent.

Counters retain known sample sums/means, unknown outcome and eligibility exposures. Exact within-log metrics become null when unknown exposures or unattributed possible actor opportunities affect the numerator/denominator. Unknown native target eligibility is retained separately rather than invented as a target. Known-source log exactness does not certify full-game completion.

The actual batch reauthenticates the original PBP parent at its original frozen prelock boundary, then reads newly captured FTN and derives at actual postlock times. This does not backdate FTN availability. Both artifacts are explicitly retrospective/nonserving; `require_feature_use` rejects registration/current forecast purposes. All original source artifacts and earlier variants remain preserved. Models and consumers are paused/pending.
