# Proposed coordinated model transition — not execution authorization

No fit, model activation, serving, optimizer or saved-lineup change has run in this discovery stage. Root coordinates the transition after defensible independent feature work/High contracts are exhausted. Unresolved source metrics may remain explicit unknowns until the user can provide access.

1. Freeze the authoritative320-ID register, actual approved feature refs, source/producer revisions and coverage/missingness contract. A catalog completion count does not mean every feature is an admissible numerical column or that every row is complete.
2. Reuse existing team/player count consumer contracts only after selecting compatible feature grains and prior-only ancestry. Current code supports matched `tree` and `neural` families in `team_opportunity_models.py` and `feature_block_model_inputs.py`; their exact ordered matrix/version/split guards must be preserved or explicitly revised with review. Do not append arbitrary242columns or substitute fantasy-point/label inputs.
3. Distinguish historical revised reconstructions from original pregame evidence. Postseason participation and retrospectively captured official statements cannot become originally available predictors merely by assigning a target cutoff. Keep publication/capture/effective clocks, conditional source coverage and availability unknowns explicit; use only justified prior inputs in each measured row.
4. Freeze one chronological train/validation/test boundary and matched official known-label cohorts before comparing families. Fit preprocessing on training only; preserve train-median imputation plus missing indicators as model-stage transformations, never source-observed zeros. Entirely unknown train columns cannot acquire an invented response at inference. No missing/zero weekly row→DNP conversion.
5. Run one bounded heavy operation at a time: matrix/contract validation, then tree fit, then neural fit on the same prepared inputs. Preserve existing estimator settings and prior fits as baselines unless root explicitly scopes a recipe change. Record actual stage clocks and unknown/label exclusions; stop for convergence or data-contract failures rather than launch grids.
6. Compare each channel against the frozen existing model and simple historical baseline on identical held-out eligible rows. Report count error, bias by relevant role/team/time cohort, sample sizes and unknowns. A two-model disagreement is not calibrated uncertainty. Any probability/quantile claim requires separate chronological calibration evidence.
7. High reviews the concrete matrix lineage, new transformations and results before any promotion. Failed or inconclusive fits remain separately identified research artifacts. Live predictions, preferences, constraints, lineups and user settings are preserved; activation is a separate coordinated decision.

Read-only code inspection found existing tree `HistGradientBoostingRegressor` and neural `MLPRegressor` consumers. This plan does not claim those existing fits, pipelines or newly collected source features have passed a new model review.
