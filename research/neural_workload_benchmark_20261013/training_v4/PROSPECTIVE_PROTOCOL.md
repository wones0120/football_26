# Reserved future evaluation: 2026 Weeks 6–9 Sunday Main

This is a reservation, not a completed experiment or scheduled automation. No Week6+ result was loaded into V4. Historical blindness could not be proven, so V4's rolling2024/2025 and2026W4/W5 comparisons are retrospective development/diagnostics.

Before each Sunday12:00 Eastern decision cutoff, save immutable player forecasts for **all canonical-mapped pregame salary/roster QB/RB/WR/TE candidates**. The future universe must come from timestamped pregame roster/salary evidence; it cannot be selected using future offensive snap participation. Retain unresolved candidates and missing features separately. The current models predict workload/PPR conditional on offensive participation; they do not estimate injury/DNP availability. Label that condition in forecasts rather than silently assigning inactive players zero.

Freeze V4 selected configurations, fitted weights, preprocessing, source definitions and candidate comparison set before observing reserved outcomes. Evaluate history, same-window prior NN/tree and both new NN approaches using the same candidate/sources. Keep weights unchanged across Weeks6–9 for the first controlled comparison; update causal prior-game features only from completed games actually captured before cutoff. Do not choose feature families or recalibrate intervals from a favorable reserved week. Any refit/feature/news treatment requires a separately identified experiment with its own decision-time receipt.

Each prediction receipt records source-file hashes/observation clocks, native-to-canonical rules, model artifact hash, code/spec hash, snapshot/timezone/cutoff, family/method/config, missingness, conditional point forecast and any empirical residual interval. Save original forecasts before lock; later reconstructions/corrections are separate lineage records. Original historical provider availability is not inferred from current downloads.

After games, record measured participation and stat sources. Preserve observed zeros, absent stats and DNP separately. Score the previously saved forecasts for the documented positive-offensive-participant conditional population, and report pregame-universe coverage/inactive/missing rows so survivorship is visible. A future unconditional fantasy projection needs a separate pregame participation model. Compare observed point/workload/ranking/interval results across all four weeks and each position; do not claim fantasy profitability or correlated lineup EV from player means/pair sums.

The existing V4 calibrators use earlier calibration periods. Their90% intervals are empirical marginal residual ranges with no conditional/time-drift/joint guarantee. If future upper-tail/lineup decisions matter, register calibrated count/quantile distributions and shared-game correlation modeling as separate work rather than relabeling these bounds as ceilings.
