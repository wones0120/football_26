# Official-inclusive workload baselines

This package adds exact official-inclusive definitions for twelve IDs whose previous measured variants excluded spikes or kneels. Those original variants and artifacts remain unchanged.

G03-M01 uses the physical union of official passing attempts (including spikes), sacks and official scrambling rushes. Each native game/play appears once; scramble is not added again to a reported dropback count. G03-M07 is QB official scrambles divided by that same official-inclusive dropback count. G03-M10 divides the player's dropbacks by the full team's dropbacks, including known native actors without canonical identity.

G06-M02 is scoped RB official carries divided by all team official carries, including kneels and QB carries. G06-M03 through M10 apply the original preplay contextual predicates to official carries, now including kneels: first/second down; third down; ydstogo<=2; Q2/Q4 halfclock<=120; Q1/Q2; Q4; score differential>0; score differential<0. No postplay score or user eligibility enters a predicate.

Historical QB/RB scope requires same native game/team/player position proof. Canonical taxonomy maps nativeFB toRB and preserves the original proof. Raw display names are never joined. Full-source team denominators and unknown native actors remain intact. Unknown conditions on a known other actor do not change an observed actor's numerator; the full-team denominator remains unknown when that condition affects it. Unattributed eligible or potentially eligible events mask affected actor exactness. Known subset exclusions do not create artificial unknown exposures. Zero denominators yield null shares.

The pure builder requires authenticated immutable parent intake. The actual retrospective reader revalidates the indexed snapshot/parent at its original evidence boundary while retaining actual read, derive and publication times. Position proof comes from the already reviewed immutable effectiveness artifact, whose native alias cardinality was separately verified. Outputs are explicitly postlock descriptive and rejected for current registration, forecast or scenarios. Within-log exactness does not certify full-game completeness or original pregame availability.

The11-test gate covers spike/sack/scramble physical union, unavailable reported-dropback flags, official kneel inclusion and team denominator, source-native backup and missing actors, known-other subset uncertainty, missing context, typed positions, excluded plays, source clocks/material changes and postlock rejection. Actual per-ID coverage and refs are in `actual_derivation_receipt.json`; source/slice/hash and official count conservation checks are in `actual_QA.json`. No fit, source download, database mutation, optimizer or shared runtime edit occurs.
