The corrected323-player-game component cohort is now known; its aggregate errors have been inspected. This is retrospective research, not a blind test. Do not change W6 selections, point projections, user preferences or eligibility. No W6 labels enter these fits.

Test whether the recorded workload proxy contains a predictable calibration error before attempting another lineup objective. Use the already-declared original pregame mean>=5 cohort, unique canonical QB/RB/WR/TE player-games with exact observed DK/component reconciliation in2026Weeks2,3,5. QB/RB target is observed carries; WR/TE target is observed targets. Missing components stay excluded and counted, never zero. Per-position fixed Poisson regression alpha=1, sole predictor log1p(original recorded workload proxy), scaler fit training only; no feature/hyperparameter search. Eight tiny fits maximum: trainW2/testW3, then trainW2+W3/testW5. No evaluation-week target enters fit. Compare unchanged proxy and training-only position-mean controls on identical rows. Report MAE, RMSE and bias, counts/games, plus paired game-cluster bootstrap MAE differences (1,000draws, seed7), explicitly small/overlapping temporal evidence.

Success for this diagnostic requires consistent MAE improvement over both controls across the two temporal folds without hidden position regressions. Mixed results remain mixed; do not retune. This does not validate FP improvement or independent player workload forecasts as a physical joint game model: predicted counts must eventually reconcile to supported whole-team opportunities before application.
