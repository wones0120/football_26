# Observed personnel-package continuity (G18-M10)

A package is a declared literal source-role-count tuple among exactly eleven unique simultaneous offensive participants. This is not an inferred formation, left/right alignment, route, blocking assignment or healthy/expected starting unit. Each unit also retains its complete participant-to-source-role map. Canonical catalog measurements require uniquely qualified frozen UUIDs; native-ID observations are retained as a separate variant.

For each measured same-team/season REG game, use the immediately preceding SCHEDULED game by authenticated native game date. Never skip missing source logs or choose the most recent available unit. First season games are not applicable, not zero. Unknown dates or ambiguous schedule order cannot establish a predecessor.

A current snap is comparable if its source-role-count tuple occurred in the prior observed eligible snap universe. Among comparable current snaps, retention means its exact participant/role set was previously observed. One matched prior set can establish positive retention even if additional prior units are unknown. Nonretention requires the prior eligible package universe to be complete; unknown prior roles, eligibility, side, participation or identity may hide a matching unit. A new role tuple is noncomparable, not automatically failed retention. Missing current proof masks the full fraction while known classified samples remain separate.

The catalog fraction is retained current physical snaps / comparable current physical snaps. Physical union is official pass attempt OR rush attempt OR sack once, including spikes/kneels and excluding source `no_play`/two-point events. Native source class/flag and explicit-null exclusions remain tri-state. Unknown side can affect either existing native team cohort; it never invents a team-qualified participant unit. A participation row without a matching REG PBP event is potentially another snap and masks completeness. Missing offense logs never become zero packages. This is completeness within the observed authenticated source cohort, not independent complete-NFL-game proof.

Per-game ratios and pooled season descriptions are separate. Pool retained/comparable snap counts before division; do not average ratios or weight unique packages equally. A full pooled ratio needs all applicable observed-game cohorts known. Zero comparable denominator is undefined; unknown is never zero. Native display sorting is not chronology.

The shared FTN position component is read once from newly cached immutable projections, with exact eleven/position/cross-side validation and original 2023–25 native source lineage. It supplies no physical eligibility; a separate minimal projection of the original immutable PBP provides that proof by native game/play/phase/team. No duplicate raw participation reads, generic snap-total proxy or per-player name join.
