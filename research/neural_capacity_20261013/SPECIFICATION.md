# Frozen neural capacity experiment

Research only: no app, database, live projections, features, source selection, or defaults change. Existing historical outcomes were inspected in earlier work. This is retrospective revised-data development, not a fresh held-out test. PPR is source PPR, not DraftKings scoring; observed participant population does not estimate DNP risk. W6+ remains reserved; no future labels loaded.

Use the exact game-context fullprecision parquet, unchanged F2 (50 numeric) / F3 (68 numeric) and position, observed positive-snap rows, observed labels including real zeros, original row indices. Context columns are excluded. Use V4 A/B/C chronological gradient-fit -> stopping -> selection -> calibration -> Sunday-main assessment partitions. Preprocessing, position priors, residual target scaling and amount smearing fit only gradient rows. Whole blocks and row identities match the tree study.

Both shared residual-to-history and position-aware hurdle workload / residual PPR heads are tested. Existing controls (16,8) alpha .05 batch128 and (32,16) alpha .2 batch256 retain 300-epoch stopping. Larger options: width (64,32), width (128,64), depth (32,16,8), depth (64,32,16). All use alpha .2, batch256, LR .001 except widest128 uses alpha .5 and LR .0007. These are joint regularized options; widest128 effects cannot be attributed only to width. Larger options allow 500 epochs. Chronological stopping retains 25-epoch patience, minimum10 and V4 metric/tolerance. Width64 vs current32 and depth32 vs current32 isolate architecture with identical optimizer/hyperparameters except maximum training budget. Runtime/epoch diagnostics disclose differences.

216 macro fits (6 architectures x2 model designs x2 feature families x3 targets x3 blocks), with multiple position heads per macro fit. 120sec/head,1200sec global CPU cap, single native thread, no GPU/cloud/dependency changes. V4 had 2 candidate configurations per model; this larger search budget is disclosed and cannot establish intrinsic architecture superiority.

Prespecify selection as mean position-normalized target MAE on selection week, deterministic index tie-break. `current_*` selects only original2 configurations; `capacity_*` selects among all6, including current. Compare each selected whole model, never assemble a winner from cherry-picked assessment metrics. Individual architecture assessment predictions are descriptive diagnostics only. Calibration uses its separate week and has no distribution guarantee. Assessment must not retune model/feature/architecture. Save freeze, configs, all selection records, curves, head parameter counts, best epochs, runtime, checkpoints, fullprecision predictions and verification. Compare frozen tuned tree when available using exact row/fold keys; summarize MAE/RMSE/bias, positions/high workload/role shift, week consistency, source PPR rankings and upside, and paired week cluster intervals with dependence caveat.
