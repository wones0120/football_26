Only new opportunity_source_capture.py and its focused tests are owned by this package. No public Prepare, optimizer, source_capture service, event taxonomy, workload, routes or UI file changed. No network fetch or production database operation ran during validation.

Provider data may be cache-backed: receipt/capture time is storage availability, not verified remote publication or freshness. Source/revision attribution and unknown original historical availability remain explicit.

`derive_opportunity_event_evidence(snapshot, *, canonical_ids, before_period, cutoff, official_components=(), limits=None)` performs actual stored artifact/manifest verification, operational source contract, current pre-lock availability and snapshot forecast-scope validation. It reads the immutable CSV preserving native identity strings and nullable flags, excludes non-REG/non-prior rows with explicit counts, checks native game period and integral native play duplicate keys, and calls the existing opportunity_events builder/validator. Missing offensive team scope is an error. Missing non-offensive scope is preserved separately with original rows; no fake team identity is created.

Optional per-player component reconciliation retains observed match/mismatch evidence and its source clocks; it does not silently certify an entire game.
