# Nominal terminal-decision field-position range

G23-M05 is proposed as the declared historical nominal35-yard terminal-decision-site family admitted by High. Principal unit: count per observed team-game of source ORIGINAL physical-offense drives ending at a corroborated opponent-yardline<=35 FG-made/missed/blocked, punt (including proven blocked punt), or fourth-down-failure predecision site. It is NOT actual actionable kick opportunity, expected attempts, made-FG ability, or a guarantee that a kick would be exactly52yards. The35 threshold is fixed, not response optimized. TD/typed original-offense giveaway/known clock-end classes are explicitly excluded, retained as separate verified categories. Unknown terminal/endpoint/cohort/order/side/half evidence masks affected exact game counts, with known lower counts separate. A complete known cohort alone can establish zero.

The primary dictionary describes drive_end_yard_line as source drive-end field position and drive_end_transition as how offense lost possession. The actual source inspection separately establishes representation: all FG/punt/INT/fumble/downs end fields match the original offense's last preplay LOS, not return landing. This narrower predecision interpretation is the feature definition. Native original-drive first/last IDs, original offense and provider order_sequence are checked against the original CSV, including every physical row's same-half evidence. No numeric-play-ID chronology is used. The reported end field is independently converted relative to the game's two native teams, with explicit50/MIDFIELD convention, and must equal the verified eligible terminal play's own preplay LOS. Unknown/conflicting field/terminal evidence stays unknown. Source last-play ID and last physical-snap ID remain distinct.

A source TD end label may point to an extra-point/try as the source last play. It is excluded only after a matched same-original-drive official pass OR rush TD is independently proven by the reviewed physical-event scoring ledger within native boundaries. Try LOS is never donated as a field-goal site. INT exclusion requires a matched official pass and native interception flag. Fumble exclusion requires the reviewed sole-fumbler/sole-recovery proof that the original offense's fumbler LOST possession, not initial-posteam donation or ordinal slot pairing; missing/multi/team uncertainty remains unknown. END_HALF requires native END_QUARTER/qtr2/zero half clock; END_GAME requires native END_GAME/qtr>=4/zero game clock AND separately authenticated completed-score proof. Positive live QB/event flags on quiet-looking control rows mask source classification. Neither EOF nor a label alone proves termination. Unsupported safety/other classifications remain unknown.
