# Highest baseline projection

In Operations, select Classic GPP and choose **Classic selection objective → Highest baseline projection · optional stacks**. Use the ordinary verified prepared run when ready, or the separate **Generate preliminary research lineups** workflow with its explicit frozen assumptions. The preliminary rank override remains request-only; it does not change stored rank preferences.

This mode submits one lineup with no player locks. It maximizes the sum of unchanged baseline `projection` values, with no ceiling, ownership, correlation or conditional-scenario bonuses. Stacks are permitted but not required. It bypasses Analyst scenario generation entirely, so a primary team/QB, receiving partner or opponent response cannot be forced by a scenario. Other user rules remain binding: canonical identity, source availability, exclusions, favored positions, salary minima, one-TE preference, team/game caps, risk limits and no offense against selected DST.

The selected objective is stored per active context. It does not modify stored lineup-count or lock preferences; the highest-projection request explicitly uses one unlocked lineup. Existing Analyst scenario generation and Showdown retain their original behavior. Returning to Analyst scenarios restores that workflow's normal intent and construction policy.

The backend request is `classic_selection_objective: "baseline_mean"` under Classic `classic_large_gpp_v1`. It rejects incoming player locks or minimum-exposure locks; the UI clears those only in this explicit request. The response `highest_projection` summary and `strategy_runtime.highest_projection` saved audit identify the exact objective, solver status, eligible count, no-lock/no-hard-stack policy and frozen input/model hash. The immutable saved audit includes the actual legal model, player-to-variable identities and objective coefficients. Optimal means highest among the eligible pool under the retained rules, not across excluded players or all conceivable future information.

Saved results show **Highest baseline projection · optional stacks**, projected points and salary. Prior generic GPP recommendations and context/correlation contribution labels are not used for this mode. Preliminary results remain `entry_ready=false`; the existing contest-CSV export block remains in force. Selecting a high projection does not establish Sunday availability or expected contest payout.
