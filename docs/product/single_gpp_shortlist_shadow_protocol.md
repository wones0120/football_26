# Single GPP shortlist shadow protocol

Fixed October 10, 2026 before this experiment is scored against outcomes.
Paid finishes are the primary evaluation target. Secondary outcomes are net-return
bounds when complete payout evidence exists and top-1% / top-10% placement. Never
select, tune or substitute a candidate based on actual points or hindsight rank.

Use the latest completed Week 5 Sunday Main Classic and Sunday Night Captain
baselines. Preserve their projections, eligibility, user preferences, salaries,
constraints and live recommendations. No changes to runtime defaults or policy.

- Classic: reproduce the original ordered five lineups and recommendation. Run one
  additional five-lineup research pass using projection weight 1 and other
  objective weights 0, with every non-objective contract value unchanged. Both
  portfolios must pass the original constraints. Compare the union with the
  unchanged projection-first recommendation ordering. This tests candidate
  coverage as well as shortlisting: current Classic generates its portfolio
  sequentially and has no larger hidden shortlist to reuse. It is not a jointly
  valid ten-lineup portfolio or a proposed portfolio export.
- Captain: use the full saved candidate audit, retaining only candidates with
  explicit quality eligibility and full-portfolio feasibility under the original
  constraints. Reconstruct each roster from the saved base forecasts and native
  salary source, verify aggregate means/P90/salaries and export legality, and
  compare with the unchanged projection-first ordering. Keep the incumbent in
  the comparison. Do not use scenario-conditioned scores or enable ownership.

The ordering maximizes common-baseline mean, with summed marginal P90 only for
exact ties and then canonical identity. It is an uncalibrated surrogate for paid
finishes. Neither a mean increase nor summed P90 establishes improved GPP results.

Freeze and register control/challenger before first kickoff. Keep an unchanged
choice as a null result. When results are imported, use the existing shadow
learning service to score both against the same actuals and verified GPP fields.
Do not fabricate return data from paid-place counts. A changed model needs
additional independent, untouched slate evidence before any live promotion.

Weeks 1–4 have already been inspected and are diagnostic context, not holdouts.
This pass does not retune thresholds on them. In particular, the observed
Week 4 Sunday-night hindsight best roster is not an optimization target.
