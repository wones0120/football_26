# Personal thoughts in Analyst preparation and saved runs

Thought Studio assigns memory using its own **Memory season**, **Memory week**, **Memory slate**, **Memory format**, and **Memory objective** selectors. These initialize once from the current optimization scope. Changing either set of selectors does not change the other, and an existing draft retains its memory scope when optimization changes. Revising a saved belief restores its original scope before editing. The raw inbox and structured composer use the visible memory scope; the library shows saved beliefs across scopes so a misplaced note can be revised without changing optimization.

Saving memory alone does not authorize use. For qualitative team concerns, enter a **Canonical team** and a separate **Conditional mechanism**, then choose **Preview Analyst review**. The immutable preview displays the exact scope and permits evidence review only. **Approve Analyst review** records the decision for that exact belief version. Preview retries return the original identical version/scope/action preview; a revision requires its own approval. The original thought text, interpretation and approval remain separate.

Preparation reads current belief versions and their latest qualitative preview decision. It excludes unapproved, rejected, inactive, expired, retrospective, future and wrong-season/week/slate/format records. The explicitly resolved canonical team must be in the preparation's canonical games. Objective-specific approvals are carried with the thought and checked again against the optimizer objective. A missing checked Analyst packet cannot claim the thought was read. No unapproved thought text enters the Analyst context receipt.

The `analyst_personal_context_v1` receipt freezes belief/version/source, preview/decision, expiry, resolved scope and canonical game IDs, checked research hash, related existing scenario IDs, and the authored research's supporting/contrary context. Team-linked research is explicitly **context**, not independent confirmation of the personal hypothesis. A separate conditional mechanism explains how the hypothesis could matter and what could offset it. Missing measurements remain explicit.

This approval is qualitative: `applied_scenario_ids` stays empty, `affected_construction` is false and no selected-roster change is attributed to the thought. A concern about offensive-line condition does not justify a fabricated injury, a passing-volume reduction, an efficiency coefficient, a scenario probability, or a player projection multiplier. The current typed Analyst operations cover declared passing/rushing volume, concentration and workload transfer; they do not supply a calibrated protection-to-efficiency response. A separately authored and reviewed typed scenario is required for a numerical construction effect.

The preparation summary and reopened saved run show **Personal thoughts: … read · … excluded · construction unchanged**, the exact thought/version/approval, linked scenarios, reasons for abstaining and research context. `analyst_handoff_applied.personal_context` and `football_analyst.prepared_research.personal_context` preserve the receipt. Ordinary and preliminary optimizers recheck current version/approval/expiry before running; changed approval requires a new preparation/freeze. Preliminary snapshots keep their original immutable handoffs; approving a thought later never backfills an older run or snapshot. No baseline projection, football fact, ownership forecast or historical evaluation is rewritten.

Use a new preliminary freeze after approving a thought to test it against an already finished preparation. Existing non-injury inputs and source checks still apply; the new freeze is separately identified and remains not entry cleared. No export or contest submission is part of this workflow.
