# Sunday Main projection audit and generation shadow protocol

Scope: frozen 2026 Week 5 Sunday Main run, before kickoff. Audit canonical IDs,
projection/quantile consistency, input timestamps, role evidence completeness,
projected workload, and the currently recommended players. Historical statistical
features are distinct from explicit forward-looking role estimates. Missing
forward-looking estimates must not be reported as complete workload evidence.
This is not a fresh external injury/news check or final entry approval.

Require exact saved roster and recommendation parity on the current generator
and matching implementation/solver fingerprints before any shadow executes.
Two separate fixed arms, neither selected using outcomes:

- Mean-led: transfer 0.20 normalized objective weight from marginal ceiling to mean;
  preserve correlation, leverage, context mechanism and all user constraints.
- Template rotation: rotate the existing stack-template cycle by one step; preserve
  all weights, constraints and player inputs. This isolates ordering effects.

Keep candidate count, player eligibility, salaries, predictions, ownership, exposure,
overlap, stacking constraints, game/team caps and live projection-first selector.
Each shadow must independently pass the same portfolio audit. Save forecasts,
rosters, traces, source/config hashes and prelock completion timestamps separately.
No database writes or live routing. Upcoming outcomes are unknown; do not claim
paid-finish or expected-return improvement from higher projected points alone.
This scoped runner does not claim to backtest these arms on historical slates.
